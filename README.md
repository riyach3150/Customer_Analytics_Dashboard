# Customer Analytics Dashboard

## Project Overview
This project focuses on analyzing customer data to understand customer behavior, purchasing patterns, customer segmentation, and business performance.

The dashboard transforms raw customer data into meaningful visual insights using Microsoft Excel, supporting data-driven business decisions.

## Objectives
- Analyze customer purchasing behavior.
- Understand customer demographics and segmentation.
- Identify customer trends and patterns.
- Monitor important customer KPIs.
- Generate meaningful business insights.

## Tools & Technologies
- Microsoft Excel
- Data Cleaning
- Data Analysis
- Pivot Tables
- Charts & Visualizations
- Dashboard Development
